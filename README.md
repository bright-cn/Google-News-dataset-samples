此 **Google 新闻数据集样本**包含 **1,000 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名称 | 描述 |
|------------|-------------|
| `url` | 发布商网站上完整新闻文章的直接链接。 |
| `title` | 新闻文章的标题，概述其主要主题。 |
| `publisher` | 发布该文章的组织或个人名称。 |
| `date` | 文章发布的日期和时间，采用 ISO 8601 格式。 |
| `category` | 新闻文章所属的主要类别或体裁。 |
| `keyword` | 与文章相关的关键术语或短语，用于搜索和分类。 |
| `country` | 新闻文章的来源国家或主要受众所在国家。 |
| `image` | 新闻文章相关主图的 URL 链接（如有）。 |


## 使用场景

### 1. 媒体趋势分析
分析媒体报道随时间变化的趋势，了解不同类别和国家的公众兴趣与媒体关注重点。

### 2. 竞争分析
深入了解不同发布商如何报道相似主题，帮助企业有效制定媒体传播策略。

### 3. 关键词研究
识别新闻文章中的热门关键词，优化 SEO 策略和内容创作，提升目标受众的互动度。
